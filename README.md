# x-cleaner

X (Twitter) 批量屏蔽垃圾/引流账号的油猴用户脚本。

按「用户名 / @handle 关键词」或「推文正文关键词」自动扫描当前页面并批量屏蔽命中的账号，支持永久关键词列表、临时关键词、干跑预览、进入推文详情页自动运行。

## 安装

1. 先安装用户脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（推荐）/ Violentmonkey。
2. 点击下面的链接一键安装（管理器会自动识别）：

   **[安装 x-block-spam.user.js](https://raw.githubusercontent.com/forever-utf8/x-cleaner/master/src/x-block-spam.user.js)**

安装后打开 `x.com`，右下角会出现「X 批量屏蔽」浮动面板。脚本会随 `@version` 提升自动检查更新。

## 用法

- **临时关键词**：在输入框填词 → 点「扫描并屏蔽」（或回车）只对本次扫描生效。
- **永久关键词**：在输入框填词 → 点 `➕`，写入本地永久列表并**立即扫描屏蔽一次**；对用户名和正文都生效，`localStorage` 落盘。
- **干跑（DRY_RUN）**：只高亮命中、不真正屏蔽，首次使用建议先开。
- **自动运行**：进入推文详情页（URL 含 `/status/`）或滚动加载新内容时自动扫描屏蔽。

## 配置

脚本顶部 `CONFIG` 可调：

| 项 | 默认 | 说明 |
|---|---|---|
| `DELAY_MIN_MS` / `DELAY_MAX_MS` | `0` / `0` | 每次屏蔽之间的随机延时（毫秒）。默认最快、几乎无感；若触发频控请调回 `50`~`150` |
| `MAX_BLOCK_PER_RUN` | `30` | 单次运行最多屏蔽数，保护账号 |
| `DRY_RUN` | `false` | 干跑预览 |
| `AUTO_RUN` | `true` | 自动运行 |

## ⚠️ 风险提示

本脚本会**自动化批量操作你的 X 账号**（连续屏蔽）。高频操作可能触发平台风控，请自行评估账号风险，建议保留一定延时并控制单次数量。仅供学习与个人使用。
